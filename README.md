# BuildForge PC Store

ASP.NET Core MVC (.NET 7) + SQLite + Bootstrap 5 — university group project.

## Run

1. Open `BuildForgePcStore.sln` in Visual Studio.
2. Rebuild solution → press **F5**.
3. Database `buildforge.db` is created automatically on first run.
